# Retail Sales Analysis

## About the Project
An Exploratory Data Analysis (EDA) project on an Online Retail transaction dataset using Python.

## Objectives
- Understand and clean retail transaction data.
- Analyze sales and revenue patterns.
- Identify top-selling products.
- Explore country-wise sales.
- Understand customer purchasing behaviour.
- Discover useful business insights through data visualization.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Structure
- `notebooks/` – Jupyter Notebook containing the analysis.
- `data/` – Dataset stored locally (not included in this repository).

## Dataset
Online Retail transaction dataset. Download it from the original dataset source and place the CSV file inside the `data` folder.
